# 🍽️ Meal Explorer - Discover & Search Delicious Recipes! 🍕🥗  

A simple web app to explore meals from around the world. 🌍🔍  
Search for your favorite dishes, view details, and get cooking instructions. 🍳✨  

## 🚀 Live Demo  
🔗 [Live Project](https://rakibul263.github.io/Meal-Explorer/)  

## 💻 Features  
✅ Search meals by name 🍜  
✅ Get detailed meal information 📖  
✅ View meal categories & origins 🌎  
✅ Simple & responsive UI for a smooth experience 💡  

## 🛠️ Technologies Used  
- HTML5 & CSS3 🎨  
- JavaScript (ES6+) ⚡  
- Bootstrap 5 🎭  
- TheMealDB API 🍽️
